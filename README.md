# БезКода Агент

**ИИ-помощник для работы с проектами, файлами и кодом на вашем компьютере.**

[Сайт БезКода](https://bezcoda.ru) · [Открыть Платформу](https://platform.bezcoda.ru) · [Начать работу](https://platform.bezcoda.ru/cabinet/agent) · [Релизы](https://github.com/olegpavlich/bezcoda-agent/releases)

</div>

Опишите задачу обычными словами. БезКода Агент помогает изучить материалы, составить план, работать с кодом и подготовить результат в вашем проекте.

## Что можно делать

| Задача | Как помогает Агент |
| --- | --- |
| Разобраться в проекте | Изучить структуру, найти нужные файлы и объяснить, как всё устроено |
| Создать приложение | Превратить идею в прототип и проверить основной сценарий |
| Исправить ошибку | Найти причину, подготовить изменения и выполнить проверки |
| Подготовить отчёт | Разобрать предоставленные таблицы и документы, сформулировать выводы |
| Автоматизировать рутину | Подготовить сценарий для повторяющейся работы |
| Разобрать задачу по 1С | Изучить доступную выгрузку конфигурации и составить план доработки |

Для задач нужны соответствующие файлы, инструменты и доступы. Готовые примеры промптов доступны в разделе **«БезКода Агент»** на Платформе.

## Скачать

**Первый установочный релиз готовится.** Установщики и описания изменений будут публиковаться в [GitHub Releases](https://github.com/olegpavlich/bezcoda-agent/releases).

В каждом выпуске будут указаны версия, поддерживаемые системы, системные требования и список изменений. Выбирайте установщик для своей системы из раздела **Assets**. Автоматические архивы **Source code** содержат файлы этой страницы, а не установщик приложения.

## Первый запуск

1. Скачайте опубликованный установщик и установите приложение.
2. Откройте БезКода Агент и выберите вход через БезКода Платформу.
3. Войдите в свой аккаунт или зарегистрируйтесь на Платформе.
4. Откройте папку проекта, создайте чат и опишите задачу.

У Платформы и Агента одна учётная запись. На [странице Агента](https://platform.bezcoda.ru/cabinet/agent) можно выбрать и скопировать готовое задание, а затем открыть установленное приложение и вставить текст в новый чат.

## Сообщить о проблеме

Создайте [обращение в Issues](https://github.com/olegpavlich/bezcoda-agent/issues). Укажите версию Агента, операционную систему, шаги воспроизведения, ожидаемое поведение и текст ошибки. Не публикуйте пароли, API-ключи и приватную переписку. Предложения по улучшению тоже можно оставить в Issues.

## Об этом репозитории

Это публичная страница продукта и место распространения готовых выпусков **БезКода Агента**. Здесь размещаются документация, описания изменений и файлы релизов. Исходный код приложения в этом репозитории не публикуется.

БезКода Агент создан на базе [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness). БезКода Платформа предоставляет общий аккаунт и доступ к моделям; приложение работает с проектами на компьютере пользователя.
